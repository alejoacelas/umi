Hidden panes

Where a pane can be in Umi, five ways to show panes that are out of sight, and the visual signals Umi could use for them. Mock content; config and CLI lines are illustrative, not decided.

Four places a pane can be

Every pane is in exactly one of these. Its program keeps running in all four, until a closed pane's 60 seconds run out.

On show

It has a place in the tab's split. The cyan line marks the focused one.

umi pane show p3
{ "id": "p3", "tab": "t1",
  "place": "shown", "focused": true }

Stacked

notes.mdplan.mdtodo.md

It shares a place with other panes; the strip on top names them and one is on show.

umi pane stack p4 --onto p3
{ "id": "p4", "place": "stacked",
  "stack": ["p3", "p4"], "shown": false }

Hidden

deploy check

It stays in its tab with no place in the split. A condition can bring it back by itself.

umi pane hide p5 --until 'agent.done=false'
{ "id": "p5", "tab": "t1", "place": "hidden",
  "until": "agent.done=false" }

Closed, reopenable

⇧⌘T · 42 s

For 60 seconds after closing, its program still runs and umi reopen brings it back where it was.

umi reopen --list
{ "items": [{ "kind": "pane", "panes": ["p6"],
  "place": "closed", "expires_in": 42 }] }
